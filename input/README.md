# Input folder

Add your context here. The planner reads all `.txt`, `.md`, and `.json` files from this folder when you run `python run_planner.py`.

- **.txt** — Raw notes, fragments, ideas
- **.md** — Markdown notes
- **.json** — Structured notes (content extracted from common keys like `content`, `notes`, `text`)

No special structure required. Drop files and run the planner.
